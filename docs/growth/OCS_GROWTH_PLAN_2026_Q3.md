## Part 1: Content Strategy — The Carta Playbook, Adapted

### 1.1 Why Content Is the Primary Growth Lever

Carta drives 200K+ organic visits/month primarily through "What is X?" educational posts that rank #1 for terms like "What is a 409A valuation?" and "What is vesting?" — simple, unsexy, SEO-first content. Their top 15 organic pages are almost all educational blog posts, not product pages. This is the playbook to replicate at smaller scale.

OpenCap Stack's advantage: Carta has abandoned the startup audience with enterprise pricing ($10K-$25K/yr). Content targeting cost-conscious founders, first-time equity issuers, and Carta refugees has low competition and high conversion intent.

## Part 3: Agent Automation — Strapi + Claude Code Content Pipeline

### 3.1 Architecture

```
Claude Code Agent (scheduled)
    |
    ├── 1. Content Generation
    |   ├── Research: WebSearch for current data, stats, competitor pricing
    |   ├── Draft: 1,500-2,500 word blog post with target keyword
    |   ├── SEO: Meta title, meta description, slug, internal links
    |   └── Image: Generate unique featured image prompt for each post
    |
    ├── 2. Strapi Publishing
    |   ├── Create post via Strapi REST API
    |   ├── Set slug, SEO metadata, category, tags
    |   ├── Schedule publication date/time
    |   └── Verify post is live and in sitemap
    |
    └── 3. Distribution
        ├── Generate social snippets (LinkedIn, Twitter)
        ├── Queue newsletter mention via Resend
        └── Log to ZeroPipeline for tracking
```

### 3.2 Implementation Plan

**Step 1: Create the content generation agent script**

Build a Claude Code scheduled agent that runs daily at 06:00 UTC (using the existing `schedule` skill). The agent:

1. Reads the content calendar from a JSON file in the repo (`docs/growth/content-calendar.json`)
2. Checks today's date against scheduled posts
3. If a post is due today:
   a. Uses WebSearch to gather current data, stats, and competitor info for the topic
   b. Generates a 1,500-2,500 word blog post following the SEO template (see below)
   c. Generates a unique featured image description
   d. Publishes to Strapi via the REST API with proper slug, metadata, and scheduling
   e. Generates social media snippets for distribution
   f. Logs the result

**Step 2: Content calendar JSON format**

```json
{
  "posts": [
    {
      "id": 1,
      "scheduled_date": "2026-06-23",
      "title": "What Is a Cap Table? The Founder's Complete Guide for 2026",
      "slug": "what-is-a-cap-table",
      "target_keyword": "what is a cap table",
      "secondary_keywords": ["cap table definition", "capitalization table", "startup cap table"],
      "cluster": "educational",
      "word_count_target": 2500,
      "internal_links": ["/blog/how-to-create-a-cap-table", "/blog/carta-alternatives"],
      "cta": "signup",
      "status": "scheduled"
    }
  ]
}
```

**Step 3: Blog post SEO template (for the agent to follow)**

Every generated post must include:
- H1 title containing primary keyword (naturally, not stuffed)
- Meta title: 50-60 characters, keyword-first
- Meta description: 150-160 characters, includes keyword + CTA
- Introduction: 100-150 words, keyword in first paragraph
- Table of contents (auto-generated from H2s)
- 4-7 H2 sections, each 200-400 words
- At least 1 comparison table or data visualization
- Internal links to 2-3 other OCS blog posts
- External links to 2-3 authoritative sources (YC, SEC, IRS)
- CTA section at the end: "Try OpenCap Stack free" with signup link
- FAQ section with 3-5 questions (targets featured snippets)
- Structured data / schema markup hints in the metadata

**Step 4: Strapi API integration**

```bash
# Create a blog post via Strapi REST API
curl -X POST "https://cms.opencapstack.com/api/articles" \
  -H "Authorization: Bearer $STRAPI_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "title": "What Is a Cap Table?",
      "slug": "what-is-a-cap-table",
      "content": "<markdown content>",
      "seo_title": "What Is a Cap Table? Complete Founder Guide 2026",
      "seo_description": "Learn what a cap table is, why...",
      "category": "guides",
      "tags": ["cap-table", "equity", "founders"],
      "publishedAt": "2026-06-23T09:00:00.000Z"
    }
  }'
```

**Step 5: Mandatory rules for the agent (from existing skills)**

- ALWAYS include slug parameter (strapi-blog-slug-mandatory skill)
- ALWAYS use unique featured images (strapi-blog-image-unique skill)
- Never include AI attribution in published content
- Verify post appears in sitemap after publishing

### 3.3 Scheduling with Claude Code

Use the `schedule` skill to create a cron trigger:

```
/schedule create --name "daily-blog-publisher" \
  --cron "0 6 * * *" \
  --prompt "Read docs/growth/content-calendar.json. If a post is scheduled for today, generate the full blog post following the SEO template in docs/growth/OCS_GROWTH_PLAN_2026_Q3.md Part 3.2, publish it to Strapi, and generate social snippets. Log results."
```

Create a second agent for content review:

```
/schedule create --name "weekly-content-audit" \
  --cron "0 9 * * 1" \
  --prompt "Check GA4 for the past 7 days of blog performance. Identify top 3 posts by pageviews and organic sessions. Check which scheduled posts were published successfully. Report findings and recommend topic adjustments."
```
